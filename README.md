
# CodeAlpha URL Shortener

A simple URL Shortener web application built using Python, Flask, SQLite, HTML, CSS, and JavaScript.

## Features

- Shorten long URLs with random 6-character codes
- Validate HTTP and HTTPS URLs
- Redirect short URLs to their original destinations
- Store URLs in an SQLite database
- View URL history
- Copy shortened URLs
- Delete saved short URLs
- Responsive web interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- REST API

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd CodeAlpha_URLShortener
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate it on Windows:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Run the application:

   ```bash
   python app.py
   ```

7. Open this address in your browser:

   http://127.0.0.1:5000/
